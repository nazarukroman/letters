# Помощник для игры в 5-буквенные слова

Веб-приложение для подбора русских пятибуквенных существительных по заданным условиям (Wordle-стиль). Кликай по буквам чтобы отметить состояние — подходящие слова подбираются автоматически.

---

## Стек

- **Backend**: Node.js + Hono + SQLite
- **Frontend**: Preact + Signals + Vite
- **База данных**: SQLite (~4000 слов из OpenCorpora)
- **Контейнеризация**: Docker

---

## Особенности

- Автопоиск при каждом изменении состояния буквы
- Учёт отгаданных слов (сохраняются в БД, выделяются в выдаче)
- Адаптивный интерфейс (десктоп + мобила)
- Один контейнер, без внешней БД

---

## Запуск

```bash
# Docker
make build
docker compose up -d

# Локально
pnpm install
pnpm seed        # создать БД (один раз)
pnpm dev         # фронтенд (порт 80)
pnpm dev:server  # бекенд (порт 4000)
```
